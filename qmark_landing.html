Built for academic and medical examination boards

A complete examination processing platform

Qmark is a desktop Optical Mark Recognition (OMR) and MCQ assessment platform built for academic and medical examination boards. It covers the entire lifecycle of a multiple-choice examination: designing and printing answer sheets, calibrating them against real scanned copies, reading filled-in responses in batch, applying institution-specific marking rules, and producing statistical item analysis — all from one consistent, integrated application.

Every stage was validated against real print-and-scan cycles — not designed on paper and assumed to work — so it holds up under the scanner variation, print drift, and candidate marking imperfections that real examinations produce.

Why Qmark

  • Supports three question formats — Multiple True/False (MTF), Single Best Answer (SBT/SBA), and Extended Matching Items (EMI) — across every module.
  • Printer and scanner independent — no dedicated OMR scanner or pre-printed OMR forms are needed. Answer sheets are printed on ordinary office printers and read from ordinary document scanners. Every sheet is aligned automatically as it is read, and a template can be recalibrated to a new scanner in minutes, so if a printer or MFP breaks down, the exam simply moves to another device.
  • Bubble geometry and spacing validated against real print-and-scan cycles, not just designed on paper, so it holds up under real-world scanner and printer variation.
  • Automated calibration is never trusted blindly — every detected bubble grid is shown as a visual overlay for confirmation, with drag-to-fix correction and a manual click-to-calibrate fallback.
  • A configurable marking engine handles negative marking (including true negative marks), subject-wise weighted scoring, and retrospective question removal.
  • Built-in Facility and Discrimination Index reporting identifies weak or ambiguous exam items using Top/Bottom group analysis.
  • Runs entirely as a local desktop application — candidate data and results never leave the institution's own computer.

Template Building & Sheet Design

Create New Template

Define a custom sheet's structure — question count, options per question, column blocks, and Index Number digits — as a skeleton ready for calibration. Placeholder-guided naming (e.g. MTF60Q, SBT40Q) keeps the template library organized.

Generate OMR Sheet

Design and print blank MTF / SBT / EMI answer sheets on A4 or Legal paper, with bubble size and spacing validated in real print-and-scan cycles and a built-in Check Fit before generating.

Auto Calibration

Automatically detects bubble positions from a real scanned sample. Spacing-consistency checks catch false detections, and every result is shown as a visual overlay with drag-to-fix correction before saving.

Manual Calibration

Click-to-calibrate fallback for when automated detection fails, or for complex custom sheets — a few reference clicks are enough to work out the full bubble grid, block by block.

Reading, Marking & Analysis

OMR Answer Sheet Reader

Batch-reads filled-in sheets (PDF, TIFF, PNG, JPEG) and exports results directly to Excel, with Index Number extraction, duplicate detection, and ambiguous bubbles flagged for review rather than guessed.

Test Scanner/Template Setup

Validates a scanner-and-template combination against real sample sheets before a live batch — a safe, repeatable pre-flight check that never touches real exam output.

MCQ Marking Engine

Configurable marking rules for MTF, SBT, and EMI, including true negative marking, subject-wise weighted scoring and question removal, saved as named presets for reuse.

Item Analysis

Facility and Discrimination Index per question option using Top/Bottom group comparison (default 27%), identifying weak or ambiguous items to review or exclude.

Deep Dive

MCQ Marking Engine

Configurable, auditable, and validated before a single mark is calculated.

Three Question Formats

MTF (independent true/false per option), SBT (single best answer), and EMI (extended matching, larger option sets) — all scored consistently.

Negative Marking

MTF supports Carrying Forward and Not Carrying Forward modes; SBT and EMI accept any configured mark for a wrong answer, including true negatives.

Subject-Wise Marking

A paper can be split into subjects, each with its own maximum mark, then combined into an overall result.

Question Removal

A flawed question can be removed by clearing its key, with full marks awarded to every candidate or the question excluded entirely.

Validation Before Marking

Every response is checked against its question type's allowed character set, and duplicate or malformed Index Numbers and any unresolved bubbles are flagged before marking proceeds.

Saved Configurations

Marking schemes save and reload as named presets, reusable across sessions and papers.

Deep Dive

Statistical Item Analysis

Every question option is measured for how well it discriminates between strong and weak candidates, using the classical Top/Bottom group method — helping identify items that should be reviewed, corrected, or excluded before results are finalized.

  • Facility Index per option — Top Group, Bottom Group, and All Candidates.
  • Discrimination Index per option, with a configurable group size (default 27%).
  • A simpler Raw Analysis tally (Right / Wrong / Omit) for a quick, type-agnostic overview.
